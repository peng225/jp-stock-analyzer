# jp-stock-analyzer
個人で使う用の株分析ツール。データは以下のものを使わせてもらっている。  
https://irbank.net/download

ただし、ダウンロードしたファイルに付与されている日本語のヘッダーは削除されていることを前提としている。また、ファイルは `data/<年度>` という形式のディレクトリに置く必要がある。

分析ツールのビルドは普通に `go build` すればよい。

PL の一部データをグラフで見るための機能もある。そちらは `stock-chart` ディレクトリで `npm run dev` を実行するなどすればよい。ただし、事前に `stock-chart/.env` ファイルを作成し、以下のように値を設定しておく必要がある。

```
STOCK_DATA_DIR=/path/to/data/dir
```

`STOCK_DATA_DIR` で指定したディレクトリにはダウンロードしたファイルのうち PL のデータだけを複数年分入れておくことを想定している。元データは `data/<年度>` にあるので、そこから PL のファイルだけシンボリックリンクを張るのが良いだろう。
